# Stockhub

Stockhub is a store inventory management system built with FastAPI. It allows users to efficiently track, manage, and organize stock across multiple categories, ensuring optimal inventory levels and improved decision-making.

## Features

- **Stock Management**: Add, update, and delete inventory items.
- **Category Management**: Organize products by categories.
- **Real-time Updates**: Get the current status of stock levels.

## Technologies

- **FastAPI**: For building the backend API for high performance and simplicity.
- **Python**: As the programming language.
- **SQLAlchemy**: For database interaction.
- **Uvicorn**: For running the FastAPI application.
